# 🛒 E-Commerce Backend

A production-inspired E-Commerce REST API built with **Java 25** and **Spring Boot 4**.

## 🚀 Tech Stack

* Java 25
* Spring Boot 4
* Spring Security
* Spring Data JPA (Hibernate)
* MySQL 8
* Redis
* RabbitMQ
* MinIO
* Flyway
* Docker
* JWT Authentication
* Swagger / OpenAPI

## ✨ Features

* JWT Authentication & Authorization (RBAC)
* Product, Category & Brand Management
* Shopping Cart
* Order & Checkout
* Inventory Management
* Redis Caching
* RabbitMQ Event Processing
* File Upload with MinIO
* Flyway Database Migration
* RESTful APIs
* Global Exception Handling
* Unit & Integration Testing
